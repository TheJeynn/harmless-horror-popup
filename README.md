# Harmless Horror Popup

A small Python desktop application that demonstrates a harmless scareware-style popup for educational and entertainment purposes.

The application displays a horror-themed window with an animated skull, a creepy interface, and an optional evil laugh sound effect.

## Features

- Animated skull using Tkinter Canvas
- Horror-themed desktop interface
- Optional WAV sound effect
- Play and stop audio functionality
- Simple close button
- No external Python libraries required

## Requirements

- Windows
- Python 3.x

The application uses Python's built-in modules:

- `tkinter`
- `winsound`
- `threading`
- `pathlib`

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/harmless-horror-popup.git
   ```

2. Open the project directory:

   ```bash
   cd harmless-horror-popup
   ```

3. Place your `evil-laugh.wav` file in the same directory as `main.py`.

4. Run the application:

   ```bash
   python main.py
   ```

## Safety & Disclaimer

This project is completely harmless and intended for educational purposes.

- Does not install malware.
- Does not modify Windows settings.
- Does not access personal files.
- Does not run automatically at startup.
- Does not hide itself or run in the background.
- Only plays audio after the user clicks the sound button.

The application must be started manually by the user.
